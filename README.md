# BetterBrave

Giving Brave that extra flair.

## Overview

BetterBrave is a project designed to enhance and customize the Brave browser experience with additional features, styling, and functionality. Whether you're looking to personalize your browser or add new capabilities, BetterBrave has you covered.

## Features

- ✨ Enhanced UI customization
- 🎨 Custom styling options
- ⚡ Performance improvements
- 🔧 Additional browser features

## Tech Stack

This project is built with:
- **JavaScript** (58%) - Core functionality and interactivity
- **CSS** (23.9%) - Styling and visual design
- **HTML** (18.1%) - Markup and structure

## Installation

1. Clone the repository:
```bash
git clone https://github.com/ThinuxBOOM/BetterBrave.git
cd BetterBrave
```

2. Follow the setup instructions for your specific use case.

## Usage

1. Turn on developer mode in brave after navigating to Manage Extensions
2. Click on load unpacked and navigate to where you cloned the repository and navigate inside the BetterBrave folder and click on the "Select" folder. (do     NOT navigate inside it)
3. Click open and load the extension
4. Open a new tab and select "keep changes" when prompted by Brave
5. If brave displays a footer with the button "customize brave", click it and toggle the footer off
6. In the new tab, click on the settings button in the bottom right corner to configure the new tab
7. Enjoy!
