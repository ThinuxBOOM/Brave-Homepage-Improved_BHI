                Markets — Stocks

                Both keys are saved at once, whichever source is active above — switching sources won't lose the other key.

                Refresh every

                Finnhub: free key at finnhub.io/register. Twelve Data: free key at twelvedata.com. If one source goes down or changes its terms, switch to the other — no update needed. Free plans have daily/per-minute call limits — each ticker uses one call per refresh, so more tickers or a shorter interval uses your quota faster. The trend graph is now built from prices sampled locally over time (no extra API calls), so it works the same on either source and starts filling in a few refreshes after you add a ticker.

                Markets — Currency

                Frankfurter uses European Central Bank reference rates, no key needed, been stable for years. Open ER-API is a free no-key mirror as a backup.

                Markets — Gold

                Free, no-key gold spot price. If this source ever goes offline, let me know the new one and I'll wire it in the same way — the settings and widget won't need to change.
